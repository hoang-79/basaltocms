Le présent contrat régit la manière dont vous pouvez utiliser le logiciel Basalto. L'achat d'une licence et le compte
client sur basaltocms.com sont en outre régis par les [Conditions générales](agb.md), et les données par la
[Déclaration de protection des données](datenschutz.md). Le même contrat figure dans le dépôt sous le nom
`LICENSE.md`, avec le champ d'application défini pour chaque partie du dépôt.

## En bref (ne fait pas partie du contrat)

Vous pouvez lire, exécuter et adapter pour vous-même le code source de Basalto. Basalto est gratuit pour un site avec
un utilisateur du backend — avec tous les modules —, ainsi que pour le développement, les tests et l'usage privé. Si
vous utilisez Basalto à des fins commerciales avec plusieurs utilisateurs ou plusieurs sites, il vous faut une licence
Site ou Agence. Basalto vérifie la clé hors ligne et ne nous envoie rien. Sans clé valable, Basalto continue de
fonctionner, mais affiche des avis : immédiatement dans le backend, après 30 jours dans le frontend. Basalto ne bloque
jamais aucune fonction.
